## Supplemental Scripts

The code in this folder is non-critical to the data paper for which this repository was created. However, they are potentially relevant to the larger efforts of the [Life After Death](https://lternet.edu/working-groups/life-after-death-how-legacies-of-dead-foundation-species-influence-ecological-processes-across-marine-and-terrestrial-ecosystems/) working group and so are included in this repo.
