# LTER SPARC Group: Material Legacy Effects

Principal Investigators: _Dr. Kai L. Kopecky, Dr. Katharine N. Suding, Dr. Ty A. Tuff_

## Workflow Explanation

1. `00_download/` -- Downloads raw data from the [Environmental Data Initiative](https://edirepository.org/) (EDI)
2. `01_standardize/` -- Does site specific wrangling to generate analysis/visualization-ready data
3. `02_analyze.r` -- Fits appropriate statistical models to _all_ sites' data
